# Project-Base

A reusable base repository for AI-assisted software projects.

This repository keeps persistent agent instructions small and reviewable, while placing detailed workflow and context guidance in dedicated documents.

To apply these conventions to an existing repository, follow [ADOPTION.md](ADOPTION.md).

## Structure

```text
Project-Base/
├── AGENTS.md
├── ADOPTION.md
├── README.md
└── docs/
    ├── agent-context-guideline.md
    └── agentic-ai-coding-workflow.md
```

## Purpose

Use this repository as the starting point for new projects so that common AI coding practices remain version-controlled, inspectable, and consistent across projects.
